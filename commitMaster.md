# Okaye Beispiele

## Improve readability

* Von welchem Teil vom Code wurde die Lesbarkeit verbessert?

* Es haette eine genauere Beschreibung hinzugefuegt werden koennen welcher Teil genau verbessert wurde.

* Wenn der Code noch keinen großen Umfang hat.

* Improve readablity of Codepart XY

## Rename Variables

* Welche Variablen genau wurden geaendert und in welchem Teil des Codes?

* Eine Angabe, welche Variablen geaendert wurden.

* Wenn es noch nicht viele Variablen in einem File gibt.

* Renamed Variables var1 and var2 in example.java


## Add null check

* Null Checks koennen an vielen Teilen von einem Code benoetigt werden. An welchem Teil wurde er hinzugefuegt?

* Wo ein Null Check hinzugefuegt wurde

* Wenn es nur einen Null Check im Programm gibt.

* Add null check for calculator


## Fix issue #23

* Was ist das issue?

* Eine Angabe, welches Problem gefixt wurde.

* Die Nummer deute darauf hin das es vielleicht z. B. ein File gibt in dem die issues samt Nummer dokumentiert werden.

* Fix issue Nullpointer Exem
